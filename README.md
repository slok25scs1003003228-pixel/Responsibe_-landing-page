# Nexa – Responsive Landing Page

## About the Project

Nexa is a modern and responsive product landing page created as part of my internship task. The main goal of this project was to build a clean, professional, and responsive website using only HTML, CSS, and Vanilla JavaScript.

## Features

- Responsive design for desktop, tablet, and mobile
- Semantic HTML5 structure
- Responsive navigation bar
- Mobile hamburger menu
- Hero section with dashboard preview
- Features section
- How It Works section
- Customer testimonials
- Statistics section
- Pricing section
- Call-to-action section
- Email signup form
- Smooth scrolling
- Scroll reveal animations
- Responsive Flexbox and Grid layouts
- CSS variables for consistent styling

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- CSS Flexbox
- CSS Grid
- CSS Media Queries
- Google Fonts

No frameworks such as React, Bootstrap, or Tailwind CSS were used.

## How It Works

The `index.html` file contains the main structure of the website. The `style.css` file is used for the complete design, layout, colors, typography, and responsive behavior. The `script.js` file handles the interactive features such as the mobile menu, scroll animations, active navigation, and signup form.

## Responsive Design

The website automatically adjusts its layout according to the screen size. On desktop screens, the content is displayed using multi-column layouts, while on tablets and mobile devices the sections change to a single-column layout. The navigation also changes into a hamburger menu on smaller screens.

## What I Learned

Through this project, I gained practical experience in creating semantic HTML structures, designing responsive layouts, using Flexbox and CSS Grid, working with media queries, creating mobile navigation using JavaScript, adding animations, and handling form validation.

## How to Run

1. Download or clone the project.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a web browser.

For easier development, the project can also be opened using VS Code with the Live Server extension.
